# Swadesi

Buildless informational website for a proposed long-term civic collective. Swadesi is not a registered political party today. Principles and meetup details are proposals; the venue is subject to confirmation and no booking is implied.

The website uses a newspaper-inspired serif masthead, editorial columns and black-and-white rules. `brand/` contains two unselected wordmark alternatives.

## Local preview

Run `python3 -m http.server 8765 --bind 127.0.0.1 --directory site/dist` and open http://127.0.0.1:8765/. Serve only `site/dist`, never a planning workspace. No package installation or build is required.

## Scope

General-public civic information. No signup collection, payment, tracking, recruitment, supporter profiling or demographic targeting. Founder biography and personal brand assets are outside this repository.
